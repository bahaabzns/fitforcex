### 2.2 CSS RTL Overrides

```css
/* Sidebar border swap */
[dir="rtl"] .sidebar { border-right: 0; border-left: 1px solid var(--sidebar-border); }

/* Table corner radius swap */
[dir="rtl"] .table__body tr:first-child td:first-child { border-top-left-radius: 0; border-top-right-radius: ...; }

/* Tab separator repositioning */
[dir="rtl"] .tabs__list .tabs__separator { left: auto; right: 0; }

/* Search field icon margin swap */
[dir="rtl"] .search-field__search-icon { margin-right: 0.75rem; margin-left: 0; }
```

**Very Good:** Comprehensive RTL overrides for tables, tabs, sidebar, and search. The comments explain why each override is needed.

### 2.3 Tailwind RTL

The codebase uses Tailwind's `start`/`end` utilities (which respect `dir`) instead of `left`/`right`:

```javascript
// Stepper.js — uses start/end for RTL-safe positioning
className="absolute top-8 start-8 h-0.5 w-full -translate-y-1/2"
```

**Good:** Using logical properties (`start`/`end`) instead of physical properties (`left`/`right`) ensures automatic RTL support.
